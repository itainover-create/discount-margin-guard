# OPEN SKY — World Flight Simulator

**ORION GAMES** · פותח על ידי **ALON NOVITARGER** · *WHERE VISION BECOMES REALITY*

סימולטור טיסה בעולם פתוח המבוסס על כדור הארץ האמיתי: בוחרים מקום על הגלובוס, מתניעים בחניה,
מסיעים עם הפיקוח, ממריאים, טסים מעל עיר שנבנתה מנתוני מפה אמיתיים, נוחתים ומקבלים תחקיר.

![poster](web/assets/poster.jpg)

## הרצה

המשחק רץ בדפדפן (Chrome / Edge / Firefox עדכניים, WebGL 2). אין שלב בנייה, צריך רק שרת קבצים סטטי:

```bash
cd open-sky/web
python3 -m http.server 8123
# לפתוח http://localhost:8123/
```

* **"Quick flight — New York JFK"** במסך הבית מתחיל טיסה מהחניה בג'ון קנדי.
* **Missions & Tutorial**: הדרכה מודרכת (אנגלית ועברית) ושש משימות.
* **Free Flight**: גלובוס עם חיפוש (מדינה / עיר / שם שדה / קוד ICAO או IATA). אפשר להתחיל בחניה,
  על המסלול, בגישה סופית או בגובה, ולבחור יעד; המשחק מציג מרחק, זמן משוער ודלק.
* מחוץ לאזורים המפורטים, שטח ההר והגבהים נטענים מהרשת ונשמרים במטמון מקומי. בלי רשת נשארת שכבת גבהים
  גלובלית גסה שמגיעה עם המשחק, כך שכל שדה מתוך 10,446 השדות עדיין טיס.

## שליטה (ברירת מחדל; כל המקשים ניתנים למיפוי מחדש ב־Controls)

| פעולה | מקלדת | גיימפד |
|---|---|---|
| גובה (Pitch) / גלגול (Roll) | W/S או ↑/↓, A/D או ←/→ | סטיק שמאלי |
| הגה כיוון / גלגל אף | Q / E | LT / RT |
| מצערת | ‎=/-‎ או PageUp/PageDown | D-pad ↑/↓ |
| בלמים / בלם חניה | Space / B | B (עיגול) |
| מדפים | F (מטה) / V (מעלה) | X / Y |
| קיזוז (Trim) | [ / ] | D-pad ←/→ |
| תערובת דלק | U / J | |
| התנעה / כיבוי אוטומטי (מריץ את רצף המתגים האמיתי) | Shift+E | |
| קשר עם הפיקוח | T, ואז מספר האפשרות | A |
| מצלמות: תא טייס, מעקב, כנף, מגדל, חלוף, חופשית | 1–6, C למבט הבא | LB / RB |
| מבט חופשי בתא / זום | עכבר (גרירה ימנית) / גלגלת | סטיק ימני |
| טייס אוטומטי: הפעלה, HDG, ALT, כיוון ±5°, גובה ±100 | Z, X, Y, ‎, .‎, ;/' | Start |
| אורות נחיתה / חיצוניים | L / K | |
| מפה, רשימת תיוג, HUD | M, G, H | Back |
| שמירה, השהיה, עזרה, תפריט | O, P, F1, Esc | |

**תא הטייס אינטראקטיבי**: לחיצה על מתגים (סוללה, אלטרנטור, אוויוניקה, משאבת דלק, אורות, חימום פיטו),
על מפתח ההצתה (OFF-R-L-BOTH; החזקת לחצן ימני = START), גרירה או גלגלת על המצערת, התערובת, ידית המדפים
וגלגל הקיזוז, בורר הדלק, בלם החניה, וכפתורי הטייס האוטומטי והכפתורים הסיבוביים. כל מתג משנה את מצב
המערכת בליבת ה־C++: אין כפתור שרק "מציג" פעולה.

ג'ויסטיק ומצערת: Controls → Joystick, לוחצים "Bind" ומזיזים את הציר. יש רגישות, Expo, Dead zone והיפוך.

## מה יש בגרסה הזו (v1.0)

ראו [docs/TEST_REPORT.md](docs/TEST_REPORT.md) לתוצאות הבדיקות ולרשימה המדויקת של מה עובד ומה חסר.

* **מטוס**: Skylark T1, מטוס אימון מקורי עם 4 מושבים ו־180 כ"ס, מכויל למחלקת הביצועים של C172S
  (48 בדיקות כיול אוטומטיות, ראו [docs/FLIGHT_MODEL.md](docs/FLIGHT_MODEL.md)).
* **שני מצבים**: נגיש (עזרים בליבה) וסימולציה (נהלים ומערכות מלאים).
* **עולם**: 10,446 שדות תעופה אמיתיים בכל העולם, ושישה אזורים אמיתיים מפורטים:
  * ניו יורק: 1.75 מיליון מבנים, 94% מהם עם גובה מדוד, ו־JFK מפורט.
  * תל אביב / נתב"ג, הונולולו, אינסברוק, לאס וגאס וסאבה.
  * פירוט מה אמיתי ומה משוחזר: [docs/DATA_SOURCES.md](docs/DATA_SOURCES.md).
* **פיקוח (ATC)**: אנגלית תעופתית עם הסבר בעברית.
  * מסלול הסעה מחושב על גרף המסלולים האמיתי של השדה.
  * בורר מסלולים לפי הרוח.
  * בורר שימוש במסלול, משותף למטוסי ה־AI.
  * זיהוי הפרות.
* **תנועה**: מטוסי AI מבצעים פושבק, הסעה, המראה, גישה ונחיתה; מכוניות נוסעות על הכבישים.
* **סביבה**: יום ולילה לפי מיקום השמש והירח האמיתי, עננים, גשם, ערפל, רוח, משבים ומערבולות.
* **משחק**:
  * הדרכה ושש משימות.
  * ניקוד לנחיתה, למהירות ולגובה, לנהלים ולנוחות הנוסעים.
  * נקודות שמירה והתחלה באוויר.

## מבנה

```
open-sky/
├─ core/     ליבת סימולציה ב־C++17 (FDM, מערכות, טייס אוטומטי, תנועה) + בדיקות כיול
├─ web/      המשחק (WebGL2 / three.js), WASM, נתונים ארוזים
├─ tools/    צינור הנתונים ב־Python (Overture, OurAirports, Natural Earth, גבהים)
├─ tests/    בדיקות דפדפן אוטומטיות (Playwright): הסעה, המראה, נחיתה, תנועה, מצלמות, ביצועים
└─ docs/     אפיון, מפת דרכים, מקורות נתונים, מודל טיסה, ביצועים, דוח בדיקות
```

בנייה מחדש של הליבה: `cd core && make test && make wasm js` (דורש clang עם wasm-ld, ו־binaryen
עבור wasm2js). בניית הנתונים מתוארת ב־[docs/ROADMAP.md](docs/ROADMAP.md#tooling-commands).
